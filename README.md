## About this document

This document provides instructions for setting up R and RStudio
before the workshop. Participants can choose between installing
R and RStudio on their computer or using an online environment
through their web browser.

# Step 1: Set up your R environment

## Option A: RStudio Desktop (Recommended)

### Install R

1. Go to the Comprehensive R Archive Network (CRAN):
   https://cran.r-project.org/
2. Choose your operating system (Windows, macOS, or Linux).
3. Download and install the latest version of R.

### Install RStudio

1. Visit the RStudio download page:
   https://posit.co/download/rstudio-desktop/
2. Download the free desktop version and follow the installation
   instructions.
3. Open RStudio once the installation is complete.

## Option B: RStudio Online (Posit Cloud)

If you cannot install R and RStudio on your computer, you can
use RStudio directly through your web browser.

1. Visit Posit Cloud:
   https://posit.cloud/
2. Create a free account or sign in.
3. Select **New Project** and then **New RStudio Project**.
4. Once the environment opens, you can use the RStudio Console
   and execute R scripts without installing additional software
   on your computer.

# Step 2: Test your R environment

Regardless of the option selected, locate the **Console** panel
in RStudio and execute the following commands:

```r
R.version.string
print("Welcome to PeruTech Workshop 2026!")
```

If both commands execute successfully, your R environment is
ready for the workshop.
